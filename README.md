# 單字卡片盒

家庭用英文背單字網頁（學測、雅思／托福、日常與職場英文）。

- `index.html`：整個 app（單一檔案）
- `words/bNNN.json`：額外單字資料檔，檔名要列在 index.html 的 `SHARDS` 陣列
- `words/news-archive.json`：前幾天的新聞
- `words/news-gloss.json`：新聞點字查詢用的小字典
- `words/confuse.json`：易混字題庫
- `words/ceec-levels.json`：大考中心《高中英文參考詞彙表（111學年度起適用）》級數對照，著作權屬財團法人大學入學考試中心基金會，僅供非營利使用
- `words/toefl-ref.json`：托福常考字參考清單（只用來挑字）
